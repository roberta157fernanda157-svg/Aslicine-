# ASLICINE

Projeto Flutter do aplicativo ASLICINE.

## Estrutura
- `app/` — aplicativo Flutter Android
- `api/` — API Node.js
- `database/` — PostgreSQL
- `cast_receiver/` — receptor para Google Cast
- `docs/` — implantação e checklist

## Codemagic
O arquivo `codemagic.yaml` está na raiz e prepara o projeto Android antes da compilação.

> Antes de produção, configure o domínio real da API e a assinatura Android.
